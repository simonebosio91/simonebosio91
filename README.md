## 🚀 What I do

I lead development of the **Document Management Line of Business at [smeup](https://www.smeup.com)**, where I own the whole family of smeup's proprietary document management software, from product vision and architecture to the code that ships.

On the side I'm a **freelance developer**, turning ideas into web and mobile products at [webbdesigner.it](https://www.webbdesigner.it).

## 🤖 Agentic software development

I build the way modern teams will build: **AI agents as first-class teammates**.

- 🧠 Coding agents in the daily workflow with **Claude Code**
- 🧩 Shared **skills** and team rules so every agent codes like the team does
- 🔌 **MCP** integrations connecting agents to real tools and data
- ⚙️ From issue to pull request: agent-driven workflows with humans in the loop
